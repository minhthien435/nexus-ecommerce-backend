# Amazon Sales Dataset

Source: [Amazon Sales Dataset by Karkavelraja J](https://www.kaggle.com/datasets/karkavelrajaj/amazon-sales-dataset)

The repository includes `amazon.csv` so the Nexus Kaggle import workflow can be reproduced without downloading the dataset separately.

The importer uses product fields only. Reviewer, user, review title, and review content columns are ignored.
